Reference

How promotion paths work

Two principles

What they do

  • Define valid transitions for student promotion.
  • Control which destinations appear during a promotion.
  • Set display order when a class has multiple destinations.

Best practices

  • Create paths for every valid academic progression.
  • Use order to prioritise the most common destinations.
  • Deactivate a path instead of deleting it to preserve history.
